# 算数プリント自動作成（にがてはっけん）

「さんすう つみきタワー」と「算数プリントメーカー」を**合体**させた、単一HTMLの学習ツールです。
（元の2アプリはそのまま残してあります。これは"別途"つくった新しいアプリです。）

## できること
1. **診断（つみきタワー式）** … 学年をえらぶと、その学年のスキルを1問ずつ出題。
   - 正解 → できた（つみきが積み上がる）
   - はずれ → もう1問「たしかめ」→ 正解なら「あと少し」／不正解なら「にがて」
2. **けっか** …「きみは『◯◯（単元）』の『△△（スキル）』が にがてみたい」と表示。
3. **プリント自動生成** … にがて/あと少しのスキルごとに、A4れんしゅうプリントを自動作成。
   - にがて度で難易度を自動設定（にがて→★1、あと少し→★2。おまかせ／★1〜5に手動変更も可）
   - なまえ欄つき・こたえ表示・別問題・印刷/PDF（`window.print()`）に対応

## しくみ（合体のポイント）
- **診断データ**＝つみきタワーの `gn`（各スキルの `q`/`confirm`）→ `ASSESS`
- **問題生成**＝プリントメーカーの `GEN[単元キー][スキル番号](難易度)` と `TAXO`
- 両アプリは**単元キーが共通**なので、診断で得た `{key, skillIdx, にがて度}` を
  そのまま `GEN` に渡すだけで、苦手に対応したプリントが出ます。

## つかい方
`index.html` をブラウザで開くだけ（ビルド不要・外部通信なし・単一ファイル）。
