# MECE（横の論理）で考える「頼まれごとは断ってよいか」──たった3行で伝わる話し方

> 〜説得力は才能ではなく「型」である〜

説得がうまい人は、生まれつき口が達者なわけではありません。彼らは頭の中で、ある「型」に沿って言葉を組み立てているだけです。

きょうのテーマは **「頼まれごとは断ってよいか」**。
使う道具は、論理の型のひとつ **MECE（横の論理）** です。
モレなく・ダブりなく分ける。抜け漏れのない説明・網羅的な思考の型。

## 今日学ぶ型

**MECE（横の論理）**

```
全体 ┳ A ┓
     ┣ B ┃ モレなく（全部でこれで全部？）
     ┗ C ┛ ダブりなく（AとBは重なってない？）
```

👉 **どんなとき使う？** 「他にないの？」「それ、さっきと同じでは？」を防ぎたいとき。原因分析や選択肢出し。

## Before → After：弱い一言を、型で組み直す

**Before（型を知らない言い方）**

> 頼まれると断れなくて、気づいたらパンクしてるんだよな。

**After（MECE（横の論理）で組み直した言い方）**

**分ける全体**：「安請け合いより、いったん持ち帰るべきだ」を支える理由を、切り口で分けてみる。

**切り口A（事実の面）**：即答で引き受けた仕事ほど、後で予定を圧迫した

**切り口B（別の事実の面）**：「一度確認します」と返した案件のほうが、無理なく回った

**切り口C（理由づけの面）**：その場の勢いで受けると、自分の総量が見えないまま容量を超えるから

→ この3つでモレなくダブりなく言えているか、を点検する。

いかがでしょう。中身は同じでも、「並べ方」を変えるだけで、ぐっと手渡しやすくなったはずです。

## 使い方 3ステップ

- ① まず「何を分けるのか（全体）」を決める。
- ② 切り口を先に決める（時間／場所／立場／原因…）。
- ③ その切り口で並べ、「モレ(抜け)」と「ダブり(重複)」がないか点検する。

## やりがちな失敗

⚠️ 思いついた順に並べて、抜けと重なりに気づかないこと。切り口を最初に決めると防げる。

## もう一歩踏み込む

この型を「知っている」と「使える」の間には、深い谷があります。その谷を越えるための一手を置いておきます。

実践のコツは、**型を口に出す前に、指を折って数える**ことです。「主張・根拠・論拠で3つ」と物理的に数えると、抜けに気づけます。慣れるまでは、この「指折り確認」がいちばん効きます。
