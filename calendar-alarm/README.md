# 📅→⏰ カレンダー予定アラーム（5分前・バイブのみ・使用後自動削除）

Google カレンダーに登録した予定の **開始5分前** に、iPhone の **アラーム機能** を
**音なし・バイブレーションのみ** で鳴らし、使い終わったアラームは **自動で消える**
——そんな仕組みを **iPhone 単体（サーバー不要）** で作るためのセットアップ手順です。

> iPhone で読みながら設定したいときは、同じ内容の Web ページ版
> [`index.html`](./index.html) を開いてください（GitHub Pages で公開すれば iPhone から閲覧できます）。

---

## この仕組みでできること / できないこと

まず前提を正直にお伝えします。**iPhone の「時計」アプリのアラームは、Apple の制約により
外部の Web サービスや API から直接作成・削除することができません。**
プログラムから iPhone のアラームに触れる唯一の公式ルートは **iOS の「ショートカット」アプリ** です。
そこで本手順は「ショートカット」を中心に組みます。

| ご要望 | 実現方法 | 状態 |
| --- | --- | --- |
| 予定の5分前にアラーム | ショートカットで開始時刻−5分にアラーム作成 | ✅ できる |
| 音なし・バイブのみ | 無音トーンを事前設定（後述） | ✅ できる（初回だけ手動設定が必要） |
| 予定を登録したら“同時に”アラーム | iOS には「予定が登録された瞬間」を検知する仕組みがない | ⚠️ 代わりに **定期同期**（毎朝など決まった時刻に当日分をまとめて作成）で実現 |
| 使い終わったら自動削除 | 同期のたびに、前回作った予定アラームを消してから作り直す | ✅ できる |

> **「定期同期」について**：例えば毎朝 0:01 に「今日の予定」を読んでアラーム化します。
> そのため、**当日の朝より後に追加した予定** は次回の同期まで反映されません。
> これをカバーしたい場合は、後述のとおり **1日に複数回**同期を走らせるか、
> 予定を追加した直後に **ショートカットを手動で1回実行**（ホーム画面アイコン／背面タップ）してください。

## 全体像

```
Google カレンダー
   │（iPhoneの「カレンダー」アプリに同期）
   ▼
iOS カレンダー
   │（ショートカットが読み取り）
   ▼
ショートカット「予定アラーム同期」
   ├─ ① 前回作った 📅 印のアラームを全部削除（＝使用後の自動削除）
   └─ ② 今日の各予定について「開始−5分」にアラームを作成（📅 印 + 無音トーン）
   ▲
   │（毎日決まった時刻に自動実行）
オートメーション（時刻トリガ）
```

ポイントは、アラームのラベル（名前）の先頭に **`📅` という印** を付けること。
この印が付いたアラームだけを「自分が作ったもの」として、次回同期時にまとめて消します。
手動で作った普通のアラームには一切触れません。

## STEP 0. 事前準備

### 0-1. Google カレンダーを iPhone に同期する

1. iPhone の **設定** → **アプリ** → **カレンダー** → **カレンダーアカウント**
   （iOS のバージョンによっては **設定** → **カレンダー** → **アカウント**）
2. **アカウントを追加** → **Google** を選び、Google アカウントでサインイン
3. **カレンダー** のスイッチを **オン** にする
4. 「カレンダー」アプリを開き、下部の **カレンダー** から Google のカレンダーに
   チェックが入っている（表示されている）ことを確認

これで Google カレンダーの予定が iPhone の「カレンダー」アプリに入り、ショートカットから読めるようになります。

### 0-2. 無音トーンを用意して「バイブのみ」を準備する（初回だけ）

ショートカットで作るアラームは **サウンドを指定できません**。
そのため「時計」アプリの **“最後に使ったアラーム音”設定を無音にしておく** ことで、
以降に作られるアラームを **バイブのみ** にします。

**(A) 無音の着信音を用意する（GarageBand を使う方法）**

1. App Store から **GarageBand**（無料）を入れる
2. GarageBand で適当なプロジェクトを新規作成 → 何も録音せず **無音のまま 30 秒程度** のリージョンを作る
   （既存トラックの音量を 0 にする、または無音の Audio Recorder リージョンを 30 秒に伸ばすだけでOK）
3. 「マイソング」で保存 → その曲を長押し → **共有** → **着信音** → 名前を「Silent（無音）」などにして **書き出す**
4. これで **設定 → サウンドと触覚 → 着信音** の一覧に「Silent（無音）」が追加され、
   アラームのサウンド選択肢にも表示されるようになります

> 無音の着信音（`.m4r`）ファイルをすでに持っている場合は、GarageBand に読み込んで
> 手順3の「着信音として書き出す」だけでも構いません。

**(B) 時計アプリで“無音＋バイブ”のアラームを1つ手動で作る**

1. **時計** アプリ → **アラーム** → **＋**
2. **サウンド** をタップ
3. 画面上部の **触覚（バイブレーション）** をタップ → 例：**「アラート」** など好みのパターンを選ぶ
   （＝これがバイブの振動パターンになります）
4. 一覧から先ほどの **「Silent（無音）」** を選ぶ
5. アラームを **保存**（時刻は何時でもOK。これは“最後に使った設定”を無音にするためのダミーです）

これで「最後に使ったアラーム音＝無音、触覚＝オン」の状態になり、
**以降に作られるアラーム（ショートカット作成分を含む）がバイブのみ** になります。

> **⚠️ 1度だけ実機で確認してください。** iOS のバージョンによって、ショートカットで作った
> アラームがこの“最後の設定”を引き継ぐ挙動には差があります。テスト用に数分後の予定を
> （下の STEP 3 の手順で）
> 作って同期を実行し、実際に **音が鳴らずバイブだけ** で通知されるか確認してください。
> もし音が鳴ってしまう場合は、上の (B) をもう一度行ってから再テストします。

## STEP 1. ショートカット「予定アラーム同期」を作る

**ショートカット** アプリ → 右上 **＋** で新規作成し、次のアクションを上から順に追加します。
（アクションは下部の検索欄に名前を入れて探せます）

> 以下では、この仕組みが作るアラームのラベルの先頭に付ける印を **`📅 `**（絵文字＋半角スペース）
> とします。好みで別の文字にしても構いませんが、STEP①と②で同じ文字にそろえてください。

### ① 前回作った予定アラームを削除する（使用後の自動削除）

1. **「すべてのアラームを取得」**（Get Alarms）を追加
2. **「繰り返す」**（各項目を繰り返す / Repeat with Each）を追加
   - 対象＝直前の「すべてのアラーム」
   - 繰り返しの中に **「If（もし）」** を追加
     - 条件：**繰り返し項目 → 名前（ラベル）** が **「次で始まる（begins with）」** → `📅`
     - If の中に **「アラームを削除」**（Remove/Delete Alarm）を追加し、対象＝**繰り返し項目**
   - If を閉じる → 繰り返しを閉じる

> **もしお使いの iOS に「アラームを削除」アクションが無い場合**：
> 代わりに **「アラームを切り替える」**（Toggle Alarm）で **オフ** にしてください
> （＝鳴らなくなりますが一覧には残ります）。
> なお、削除アクションは **標準アプリから手動実行するより、オートメーションから実行した方が確実に動きます**
> （STEP 2 のとおりオートメーションで自動実行するので通常は問題ありません）。

### ② 今日の予定を読み、開始5分前にアラームを作る

3. **「日付」**（Date）を追加 → 現在の日付（＝“今”）。後で「過去の予定はスキップ」に使います。
   - 追加後、上部の **「変数を追加」** などから、この出力を分かりやすく **「今」** という名前にしておくと便利です
4. **「カレンダーの予定を探す」**（Find Calendar Events）を追加
   - **フィルタを追加**：
     - **開始日** → **is today（今日）**
     - **さらにフィルタ**：**終日** → **オフ（false）**（＝終日イベントを除外）
   - **並べ替え**：開始日 → 昇順（任意）
   - 上限：なし（任意）
5. **「繰り返す」**（各項目を繰り返す）を追加 → 対象＝直前の「カレンダーの予定」
   繰り返しの中に、次を順に入れます：
   1. **「日付を調整」**（Adjust Date）
      - 対象＝**繰り返し項目 → 開始日**
      - **5分** を **引く（Subtract）** → 出力を **「アラーム時刻」** と名付ける
   2. **「If（もし）」**
      - 条件：**「アラーム時刻」** が **「より後（is after）」** → 変数 **「今」**
        （＝すでに過ぎた時刻のアラームは作らない）
      - If の中に **「アラームを作成」**（Create Alarm）：
        - **時刻**：変数 **「アラーム時刻」**
        - **ラベル（名前）**：テキスト `📅 ` ＋ **繰り返し項目 → タイトル**
          （テキストアクションで `📅 ` と入力し、続けて予定タイトルの変数を差し込む）
        - **繰り返し**：**なし**
        - **スヌーズ**：お好みで（オフ推奨）
      - If を閉じる
   - 繰り返しを閉じる
6. （任意）最後に **「通知を表示」** で「今日のアラームを設定しました」等を出すと動作確認しやすいです

7. 右上（または下部）から名前を **「予定アラーム同期」** に設定して保存

> **補足：**
> - 「アラームを作成」は **時刻（時・分）** を指定すると **次にその時刻が来るタイミング** に鳴ります。
>   本ショートカットは「今日の予定のうち、まだ過ぎていないもの」だけを作るので、**当日中** に鳴ります。
> - 終日イベントを除外しているのは、「終日の5分前＝前日23:55」のような不自然なアラームを避けるためです。
>   終日予定にもアラームが欲しい場合は、STEP ②-4 の「終日＝オフ」フィルタを外し、
>   別途「開始日を今日の◯時」に補正する処理を足してください（応用）。

## STEP 2. 毎日自動で実行させる（オートメーション）

1. **ショートカット** アプリ下部の **オートメーション** タブ → **＋**（新規オートメーション）
2. **時刻** を選ぶ
3. 時刻を設定（例：**0:01**）、**毎日** を選ぶ
4. 実行内容として **「予定アラーム同期」** を選ぶ
5. **「実行前に尋ねる」を オフ**、**「実行時に通知」も オフ** にする
   （オフにすると確認なしで自動実行されます。iOS 15 以降で可能）
6. 保存

これで毎日その時刻に、当日の予定を読んでアラームを自動セットします。

### 当日に追加した予定にも対応したい場合（任意）

「定期同期」は決まった時刻に走るため、その後で追加した予定は次回まで反映されません。
気になる場合は次のいずれかを追加します：

- **同期の回数を増やす**：STEP 2 を繰り返し、**6:00 / 12:00 / 18:00** など複数の時刻オートメーションを作る
- **手動でサッと実行できるようにする**：
  - ショートカットを **ホーム画面に追加**（ショートカットを長押し → 共有 → ホーム画面に追加）して、予定を足したらタップ
  - **設定 → アクセシビリティ → タッチ → 背面タップ** に「予定アラーム同期」を割り当て、背面を叩いて実行

## STEP 3. 動作確認

1. Google カレンダー（またはiPhoneのカレンダー）に、**今から10分後くらい** に始まる予定を1つ作る
2. 「ショートカット」アプリで **「予定アラーム同期」を手動実行**
3. **時計 → アラーム** に、`📅 予定名` のアラームが **開始5分前** の時刻で追加されているか確認
4. その時刻に **音が鳴らず、バイブだけ** で通知されるか確認
5. 翌日（または次回同期時）に、その `📅` アラームが **消えている** ことを確認

うまくいかないときは、末尾の [トラブルシューティング](#トラブルシューティング) を参照してください。

## トラブルシューティング

**アラームが作られない**
- 「カレンダーの予定を探す」で対象カレンダーが正しいか、フィルタ「開始日 is today」になっているか確認
- ショートカットの初回実行時に表示される **カレンダーへのアクセス許可** を「許可」にしたか確認
- 今日の予定がすべて「終日」だと、終日除外フィルタにより0件になります

**音が鳴ってしまう（バイブのみにならない）**
- STEP 0-2(B) を再実行し、時計アプリで無音トーンのアラームを1つ作り直してから再テスト
- iPhone 本体の **消音スイッチ（マナーモード）では鳴ります**。iPhone のアラームは仕様上、消音でも音が出るため、
  “音を消す”のはあくまで **アラーム音＝無音トーン** で行います
- 「触覚（バイブ）」が **なし** になっていないか、アラームのサウンド画面で確認

**古いアラームが消えない**
- ラベルの印（`📅 `）が STEP ① と ② で一致しているか確認（全角/半角スペースの違いに注意）
- 「アラームを削除」アクションが無い iOS の場合、手動実行では消えないことがあります。
  **オートメーション経由**なら削除できます。手動でこまめに消したい場合は
  「アラームを切り替える（オフ）」に変更するか、時計アプリで手動削除してください

**当日に足した予定が反映されない**
- 「定期同期」の仕様です。STEP 2 の「当日に追加した予定にも対応したい場合」を参照

## よくある質問

**Q. サーバーや Google Apps Script は要りませんか？**
A. 不要です。すべて iPhone の「ショートカット」＋「オートメーション」で完結します。

**Q. 予定を登録した“その瞬間”に鳴らせませんか？**
A. iOS には「カレンダーに予定が追加された瞬間」を検知するオートメーション・トリガーが無いため、
本手順では **定期同期** で近似します。どうしても即時に近づけたい場合は同期回数を増やすか、
予定追加後に手動実行してください。

**Q. すでにカレンダー自体の通知（アラート）は出ます。何が違うの？**
A. カレンダーの通知は“バナー/サウンド通知”で、消音・集中モードで見落としがちです。
本手順は **時計アプリのアラーム** を使うため、より確実に **バイブで気づける** のが利点です。
